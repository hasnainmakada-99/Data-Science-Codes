03  —  TYPE SCALE (×1.5 for the 20-inch canvas)
Why every number here looks huge: the deck is 20 in wide, 1.5× a normal 13.33 in deck. PowerPoint scales the view, not the point size — so everything renders at two-thirds of its nominal value. Slide 5's 14 pt body was really 9.3 pt. The "effective" column is what the eye actually sees.

Typeface: Trebuchet MS throughout — already the deck's dominant face (507 runs) and already embedded, so nothing shifts on the client's machine. The other 11 faces (Canva Sans, Fredoka, Cinzel, Aptos, Caladea…) are removed.
Hard rule: nothing below 18 pt anywhere, including chart axis and legend text. V3's charts had text hardcoded at 14 pt.

06  —  CHART LANGUAGE — no defaults survive
BULLET BAR  — actual vs baseline vs revamp
Pale band = baseline envelope · mid band = revamp plan · solid TATA blue = actual · black tick = target. Reads in one second; a clustered bar does not.
PROGRESS RAIL  — replaces every fake progress bar
Real linked chart, axes deleted, value label inside the plot. RAG-coloured by threshold. V3's mini bars still had both axes switched on inside a 0.5 in frame.
RING GAUGE  — single-value scores
UNIVERSAL RULES
✗ No gridlines · ✗ no legend boxes · ✗ no 3-D · ✗ no pies
✓ Direct labelling on the series itself
✓ Category text 18 pt minimum
✓ One accent per chart unless comparing
✓ Every value label inside the chart object
✓ Every chart reads from the one master workbook
